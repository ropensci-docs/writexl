# Test whether an object is an \`xl_format\`

Test whether an object is an \`xl_format\`

## Usage

``` r
is_xl_format(x)
```

## Arguments

- x:

  An object.

## Value

\`TRUE\` if \`x\` inherits from \`"xl_format"\`.
