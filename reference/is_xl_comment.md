# Test whether an object is an \`xl_comment\`

Test whether an object is an \`xl_comment\`

## Usage

``` r
is_xl_comment(x)
```

## Arguments

- x:

  An object.

## Value

\`TRUE\` if \`x\` inherits from \`"xl_comment"\`.
